How to Extract a Single Page from a Large PDF

By Zainab Fuzail · Updated November 2026

A form asks for one page of your result card. A teacher wants only chapter 4. Your 200-page PDF is far too big to send. In all these cases you do not need the whole document, only a few pages. This guide shows how to take out exactly the pages you need and save them as a new, smaller PDF.

When Does This Help?

  • Online applications: upload only the page with your photo, ID or marks.
  • Study: send a single chapter or a set of questions instead of a full book.
  • Work: share one invoice or one page of a report without exposing the rest.
  • Size limits: a short PDF is much smaller than a long one.

Step 1: Find the Page Numbers

Open the PDF in any viewer and note the page numbers you need. Count pages as the viewer does, from the very first page. A book with a printed number “12” may actually be page 18 of the PDF, because cover pages are counted too.

Step 2: Extract the Pages

  1. Open PaperDesk Split PDF.
  2. Click “Choose PDF File” and select your document.
  3. Type the pages you want in the box.
  4. Click “Split PDF”. A file named paperdesk-split.pdf downloads.

How to Write the Page Numbers

  • 5 gives only page 5.
  • 2-4 gives pages 2, 3 and 4.
  • 1, 6, 9 gives pages 1, 6 and 9.
  • 1, 3, 5-7 gives pages 1, 3, 5, 6 and 7.

Use only numbers, commas and dashes. The new file always shows the pages in their normal order, even if you type them differently.

What I Tested

I tested Split PDF with a 4-page practice PDF of 6,789.4 KB. I typed 3 in the page box, and the new file was 1,697 KB, about a quarter of the original because it held one page out of four.

A Simple Example

Imagine you have a 60-page PDF with your semester results, and a scholarship form asks only for the page with your final marks. You open the PDF, see that the marks are on page 58, and type 58 in the page box. The new file has one page and is far smaller than the original, so it is easy to upload. If the form also needs your name page, type 1, 58 and you get both pages in one file.

Tips for Choosing the Right Pages

  • Write the page numbers on paper or in a note before you open the tool, so you do not have to scroll back and forth.
  • If a table or a list continues on the next page, include that page too, otherwise the reader may miss part of it.
  • For an application, check whether the portal wants the front and back of a document as two pages.
  • Include a cover or title page when the receiver needs to know whose document it is.
  • Share only what is required. If a page has private details that nobody asked for, leave it out.

Step 3: Check the New File

  • Open paperdesk-split.pdf and confirm it has the right pages.
  • Check the page count and the file size.
  • Keep your original file. The tool never changes it.

Pages are copied as they are, so text stays selectable and images keep their original quality.

Need More Than One File?

The tool creates one new PDF each time you run it. If you need several separate files, for example one per chapter, run it again with a different set of pages and rename each download so you can tell them apart. Our guide on splitting a PDF into parts explains this in more detail. If you later want to join some of the pieces again, use Merge PDF.

Common Problems

  • Invalid page error. You typed a page higher than the total, a zero, or something that is not a number. Check the total page count.
  • The file will not open. It may be password-protected. Remove the password first.
  • You need several separate files. The tool creates one new PDF per run. Run it again with a different set of pages each time.
  • Still too large. Use Compress PDF or read our guide on reducing PDF size.
  • Too large for email. Read our guide on sending a large PDF by email.

Frequently Asked Questions

Does extracting pages change my original PDF?

No. The tool creates a new file and your original stays as it was.

Can I take pages that are not next to each other?

Yes. Separate them with commas, for example 1, 6, 9. You can also mix single pages and ranges, such as 1, 3, 5-7.

Will the text in the new file still be selectable?

Yes. Pages are copied as they are, so text stays selectable and images keep their quality.

Can I change the order of the pages?

No. The new file always shows the pages in their normal order, even if you type the numbers differently.

Can I use this for a job or admission form?

Yes. It is useful when a portal accepts only one or two pages. For a full set of documents, see our guide on preparing a job application PDF.
