How to Compress a PDF to Meet an Upload Size Limit

By Zainab Fuzail · Updated November 2026

An upload form says “file too large” and refuses your PDF. Many portals accept only 1 to 5 MB, and a scanned document can easily be several times that. This guide shows how to compress a PDF in your browser, which level to try first, and how to check that the result is still readable before you submit it.

Common Upload Limits

Limits differ from site to site, so always trust the number written on the form. As a rough idea, many job and admission portals accept 1 to 5 MB per file, some government forms are stricter, and email services usually allow around 20 to 25 MB. Knowing the limit before you start tells you how much work the file needs.

Step 1: Check the Limit and Your File Size

Read the size limit next to the upload button. Then check your file size in your file manager. PaperDesk also shows the size of the selected file in KB, so you can compare it with the limit. If your file is already under the limit, you do not need to compress it.

Step 2: Compress With the Recommended Level

  1. Open Compress PDF.
  2. Click “Choose PDF File” and select your document.
  3. Leave the level on “Recommended — Balanced”.
  4. Click “Compress PDF” and wait while each page is processed.
  5. A file named paperdesk-compressed.pdf downloads, and a message under the button tells you how much smaller it became.

My Test

I tested the tool with a practice PDF of 6,789.4 KB made of photo-style scanned pages. With the Recommended level, the tool reported that the size was reduced by 92.0%, and the downloaded file was 541 KB. That is below a typical 1 MB form limit. Results depend on the file, so a PDF with fewer images may shrink much less.

A Simple Example

Suppose a scholarship portal accepts files up to 2 MB, and your scanned certificate is 7 MB. First, compress it with the Recommended level and check the new size. If it is now under 2 MB, you are done. If it is still too large, run the original file again with High Compression. If even that is not enough, keep only the pages the portal asks for, using Split PDF, and compress that shorter file.

Step 3: Use High Compression Only If Needed

If the file is still above the limit, run the original file again with “High Compression — Smaller File”. It gives a smaller result, but pages can look softer, so small print may be harder to read. Always start from your original file, not from an already compressed copy.

Step 4: Check the Result

  • Open the new file and scroll through every page.
  • Zoom in on stamps, signatures and small text.
  • Compare the new size with the upload limit.
  • Keep your original file until the upload is accepted.

What to Know Before You Compress

PaperDesk turns each page into a compressed image and builds a new PDF from those images. This suits scans and photo-heavy files. The text in the new file cannot be selected or searched. A PDF that is mostly typed text may not get smaller, and the tool will say so.

If the receiver needs searchable text, for example for a long report, keep the original file for them and use the compressed copy only for forms that need a small file.

Common Mistakes to Avoid

  • Compressing an already compressed file. Each round lowers quality. Always start from the original.
  • Choosing High Compression first. Try Recommended first, because it usually keeps pages clearer.
  • Not zooming in on the result. Stamps and signatures are the first things to blur.
  • Uploading at the last minute. Portals can be slow near a deadline. Prepare the file a day early.
  • Deleting the original. Keep it until the submission is confirmed.

If It Is Still Too Large

  • Send fewer pages. Use Split PDF to keep only the pages the form needs. Our guide on extracting a single page explains how to type the page numbers.
  • Rebuild the file from smaller photos with Image to PDF.
  • Split a long document into parts and upload them one by one. See our guide on splitting a PDF into parts.
  • If the file is for email, read how to send a large PDF by email.
  • Need to combine several documents first? Use Merge PDF, then compress the result. For a job application, see preparing a job application PDF.

Common Questions

Does compressing change my original file?

No. A new file is created and your original stays as it is.

Are my files uploaded to a server?

No. Compression happens inside your browser. See our Privacy Policy.

Which level should I choose first?

Start with Recommended — Balanced. Use High Compression only if the file is still above the limit.

Why can't I select text in the compressed PDF?

The tool turns every page into an image to reduce the size, and images do not contain selectable text. Keep your original if you need searchable text.

Why did my file not get smaller?

PDFs that are mostly typed text are already small, and turning them into images can make them larger. In that case, remove pages with Split PDF instead.
