How to Merge PDF Files on Android and iPhone

By Zainab Fuzail · Updated November 2026

Many people now handle documents only on their phone: a CV in one file, certificates in another, and a cover letter somewhere else. Job portals and offices often want everything as a single PDF. You do not need a special app for this. A phone browser is enough, and this guide shows the steps for both Android and iPhone.

Before You Start

  • Make sure all your PDFs are saved on the phone. On Android they are usually in Downloads or Documents. On iPhone they are in the Files app.
  • Use an up-to-date browser such as Chrome on Android or Safari on iPhone.
  • Rename the files with numbers (01, 02, 03) so you can recognise them in the list.
  • Password-protected PDFs cannot be merged. Remove the password first.
  • If a document is still a photo or a Word file, convert it to PDF first with Image to PDF or Word to PDF.

Merge PDFs on Android

  1. Open Chrome and go to PaperDesk Merge PDF.
  2. Tap “Choose PDF Files”. Your phone’s file picker opens.
  3. Select a file. You can select several at once, or add them one by one by tapping the button again.
  4. Check the list on the page. Files are merged from top to bottom.
  5. Tap “Merge PDFs”. A file named paperdesk-merged.pdf downloads, usually into your Downloads folder.

Merge PDFs on iPhone

  1. Open Safari and go to PaperDesk Merge PDF.
  2. Tap “Choose PDF Files”, then choose “Browse” to open the Files app.
  3. Pick your PDFs. If you cannot select several at once, add them one at a time.
  4. Check the order in the list, then tap “Merge PDFs”.
  5. When the download finishes, tap the download icon in Safari’s address bar to find paperdesk-merged.pdf. It is saved in the Downloads folder of the Files app.

What I Tested

I tested Merge PDF in Chrome on a computer with two practice files: one of 6,789.4 KB and one of 5.4 KB. The tool showed both in the list, and the merged file showed as 6.6 MB in Chrome’s download list, which matches the two sizes added together. The pages were joined without any change, so the size is roughly the sum of the files. The steps for Android and iPhone above use the same page and the same buttons, but my own test was done on a computer.

Common Situations on a Phone

  • Job application: merge your CV, cover letter and certificates into one file before uploading it to a portal that accepts a single PDF.
  • College or school forms: combine the application form, ID copy and fee receipt. Our guide on preparing a job application PDF shows a good order for documents.
  • Assignments: join the pages of your work with a cover page. If your pages are photos, read how to turn photos of notes into one PDF.
  • Bills and receipts: put several receipts into one file for an office claim or for your own records.

How to Get the Right Order

The merged file follows the order shown in the list. The tool has no drag and drop, so you cannot move a file up or down. If one file is in the wrong place, remove it with the ✕ button and add it again so it goes to the end. If several files are wrong, remove them all and add them in the order you want.

A simple trick is to add the files one by one in the exact order you need. The first file you add stays at the top, and each new file goes below it. This avoids most ordering mistakes.

A Note About Duplicate Files

If you pick the same file twice, the tool ignores the second copy, because it has the same name, size and date. If you really want the same document twice in the merged PDF, make a copy of the file with a different name first, then add both.

If Something Goes Wrong

  • An error appears. One of the files may be damaged or password-protected. Try merging with that file removed.
  • The page feels slow. Your phone does the work, so large files take longer. Close other apps and tabs.
  • The merged file is too big to send. Use Compress PDF, or read our guide on reducing PDF size.
  • You only need some pages. Use Split PDF first, then merge the parts you want. Our guide on extracting a single page explains how.
  • You cannot find the merged file. Check the Downloads folder on Android, or the Downloads folder in the Files app on iPhone.

Frequently Asked Questions

Do I need to install an app?

No. You only need a browser. Open the Merge PDF page, choose your files and download the result.

Is there a limit on the number of files?

The tool has no fixed limit. The practical limit depends on your phone’s memory and the size of your PDFs. If the page becomes slow, merge in smaller groups.

Will the quality of my pages change?

No. The pages are copied into the new file as they are, so text stays selectable and images keep their quality.

Can I merge more than two files?

Yes. Add as many files as you need, check the order in the list, and merge them in one go.

Your Files Stay on Your Phone

PaperDesk combines the pages inside your browser, so your PDFs are not uploaded to a server for merging. See our Privacy Policy for details.
